## Data and answer limitations
- Answers about assignments, submissions, courses, notes and published grades are based on records belonging to the authenticated student.
- Project questions are answered from project milestones stored for the student's enrolled courses. A separate free-form project repository is not inferred if no such record exists.
- Submission comparison/similarity is a separate professor feature; a student query cannot access another student's submission.
- The assistant does not invent assignment instructions, project details, marks, feedback or submission timestamps that are not stored in the database.
